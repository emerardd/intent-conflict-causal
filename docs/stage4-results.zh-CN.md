# Stage 4：图例前替换近零，答案前替换能改变概率偏好

日期：2026-08-28。性质：看过 Stage 3 后的有界探索性诊断，复用旧测试场景；
不是新的独立确认实验，不是 MATS 研究用时的重新起算。

## 结论先行

上一轮只证明图例前某个位置的授权相关信息可读出，却没有可靠的一维干预效应。
本轮补上整向量和分量对照后发现：

1. **图例前：**连单个位置的整条 residual 向量替换也没有可靠的正向效应。
2. **答案前：**整向量替换、以及沿该位置训练方向的单分量替换，都能使输出
   概率偏好朝配对 donor 的答案移动，且明显大于对应随机对照。
3. **仍没有行为翻转：**NF4 480 次、BF16 80 次替换，首选 token 翻转均为零。
4. BF16 两场景复查呈现相似模式，但只适合描述性比较，不能称为完整精度复现。

这削弱了“上轮无效只是因为一维不足，而同位置整向量会有效”的解释。
更值得追踪的是不同位置的可读信息如何影响下游输出。但尚未证明图例前信息
完全不被使用：冗余、其他位置和多个 token 的共同作用仍可能存在。

## 1. 这轮固定了什么

- 模型不变：Qwen3.5-4B，直接从固定 revision 的本地缓存加载：
  `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`。
- 层固定为代码索引 16，没有搜索其他层。
- 仅比较两个预先指定的位置：`pre_mapping`（字母图例前）和 `answer`
  （完整提示之后、模型回答之前的最终 chat-prefix token）。
- NF4：原测试集的 12 个场景，同措辞、候选记录在前、两种授权×两种映射，
  48 个接收样本。BF16：其中按原顺序的前两个场景，8 个接收样本。
- 每个位置的单位方向来自原 NF4 全部 64 条训练样本：未授权减授权均值，
  去除非零的训练字母均值差方向后单位化。**两个位置各有自己的方向，
  不是把同一根向量简单搬到另一个位置。** BF16 沿用这些 NF4 方向，不重新拟合。
- donor 是同场景、同候选命令、同记录顺序、同输出映射、相反授权条件的样本。
  每个精度都重新计算自己的 recipient/donor 激活。配对的完整 token 长度和
  测量索引均验证一致。
- 所有原始 Stage 3 冻结文件、报告和完整性清单保持不变。

## 2. 比较了哪些替换

令原状态为 h，配对状态为 h_d，训练得到的单位方向为 d：

```
delta = h_d - h
p = (delta · d) d
q = delta - p
```

| 模式 | 实际写入 | 要检查的事 |
|---|---|---|
| full | h + delta，即 donor 在该位置的整个 residual 向量 | 同位置整向量是否能影响输出 |
| parallel | h + p | 只替换当前方向上的配对差异是否足够产生效应 |
| perpendicular | h + q | 剩余的正交分量能产生多大效应 |
| random_full | 同 full 位移范数的固定随机正交轴 | 大位移本身是否也能产生相似效应 |
| random_parallel | 同 parallel 位移范数的同一随机轴 | 单方向效应是否超过范数匹配随机对照 |

这里“整向量”只指一个层、一个 token 的 residual 向量，不是替换整个模型
状态。随机轴每位置固定一条、与 d 正交，正反 donor 对使用同一轴的相反方向。
没有给 perpendicular 另设精确范数匹配随机轴，因此不声称验证其语义特异性。
没有 α 搜索：方向位移大小来自实际 donor/recipient 投影差。

## 3. 执行和实现检查

NF4：48 次新基线 + 480 次替换 + 2 次 null + 16 次真实单 token 生成检查。
BF16：8 次新基线 + 80 次替换 + 2 次 null + 16 次真实单 token 生成检查。
合计 56 次基线、560 次替换、4 次 null、32 次生成调用；生成在内部可能不止
一个通用意义上的模型操作，因此不把这些数量伪装成独立样本数量。

NF4 48 条基线全部精确重现 Stage 3，BF16 8 条也全部答对；两种映射准确率均
为 100%。所有生成首 token 与对应 patched forward 一致。null patch 重现基线。
patch 之后的 observer hook 记录实际写入范数和方向投影，独立审计核对了整向量
实际位移与 donor 差值。模型、输入、对齐、方向、随机轴、数据身份均有存档。

实际加载到两份模型的参数类型分别为 NF4 的 bfloat16/uint8、BF16 的 bfloat16。
BF16 自动将部分后层分配到 CPU，资源上限 GPU 6.5 GiB / CPU 6 GiB，与 NF4 的
设备分配不同。因此本轮不是“除权重精度外所有数值执行细节完全相同”的实验。
含加载的记录用时约为 NF4 161 秒、BF16 79 秒，均未触及每精度 15 分钟上限。

## 4. NF4 主诊断：12 个场景

效应定义为 patched 减 recipient 的 `log p(B)-log p(A)`，再按 donor 的正确
答案对齐符号。正值表示向相反授权条件的正确答案移动，不表示更加正确或安全。
每场景先平均四个接收样本，再对 12 个场景做 5000 次 bootstrap。单位是对数
概率差，不是正确率百分点。以下区间为探索性区间，未做多重比较校正。

| 位置 | 替换 | 平均效应 | 场景级 95% CI | 首选翻转 |
|---|---|---:|---|---:|
| 图例前 | full | −0.007812 | [−0.020833, 0.005208] | 0/48 |
| 图例前 | parallel | 约 0 | [−0.013021, 0.013021] | 0/48 |
| 图例前 | perpendicular | 0.002604 | [−0.010417, 0.015625] | 0/48 |
| 图例前 | random_full | 0.007813 | [−0.005208, 0.023437] | 0/48 |
| 图例前 | random_parallel | 0.007813 | [−0.007813, 0.023438] | 0/48 |
| 答案前 | full | **0.427083** | **[0.364583, 0.484375]** | 0/48 |
| 答案前 | parallel | **0.367188** | **[0.309896, 0.416667]** | 0/48 |
| 答案前 | perpendicular | 0.041667 | [0.010417, 0.070313] | 0/48 |
| 答案前 | random_full | 0.028646 | [0.007813, 0.049479] | 0/48 |
| 答案前 | random_parallel | 0.023438 | [约 0, 0.041667] | 0/48 |

不能只看主方向自己的区间。答案前的配对比较为：

- parallel − random_parallel：**0.343750**，CI **[0.294271,0.388021]**。
- full − random_full：**0.398438**，CI **[0.341146,0.453125]**。
- full − parallel：0.059896，CI [0.026042,0.091146]。
- full − perpendicular：0.385417，CI [0.333333,0.429687]。

答案前 full 在正常/反转映射的均值分别为 0.53646/0.31771；parallel 为
0.50521/0.22917，均朝 donor 的语义答案移动，而不是只提高某个固定字母。
但随机轴并非精确零效应，所以报告直接的配对主减随机差异。

效应幅度仍有限：按每条样本的自然 donor-recipient margin 差归一化后，
答案前 full 的平均恢复比例约 **5.14%**，parallel 约 **4.22%**。这解释了为何
可以出现清楚的 margin 变化，却没有首选输出翻转。该比例不是因果中介占比，
也不等于准确率变化。full 与两个分量的效应不必相加，不能把约 0.367/0.427
的数值比解释成“这根方向承担了 86% 的模型决策”。

## 5. BF16 对照：仅比较相同两个场景

下面 NF4 也只取与 BF16 完全相同的 8 个接收样本，不把 NF4 全 12 场景均值
与 BF16 两场景均值直接当作配对精度差异。这里不计算确认性置信区间。

| 位置/替换 | NF4 相同两场景 | BF16 两场景 |
|---|---:|---:|
| 图例前 / full | 约 0 | 0.031250 |
| 图例前 / parallel | 约 0 | 约 0 |
| 图例前 / perpendicular | 约 0 | 0.015625 |
| 图例前 / random_full | 0.015625 | 0.015625 |
| 图例前 / random_parallel | 0.015625 | 0.015625 |
| 答案前 / full | 0.515625 | 0.578125 |
| 答案前 / parallel | 0.406250 | 0.390625 |
| 答案前 / perpendicular | 0.109375 | 0.156250 |
| 答案前 / random_full | 0.031250 | 0.125000 |
| 答案前 / random_parallel | 0.031250 | 0.078125 |

在这个小子集上，答案前主要效应仍大于随机轴，图例前单方向仍近零；两精度
都没有任何首选翻转。这不支持把上轮现象简单归咎于 NF4，但不足以排除所有
精度敏感性，尤其随机/剩余分量幅度有所不同，BF16 仍然是有限精度而非 FP32。

## 6. 对研究思路的实际更新

**之前：**不知道是选出的单方向不足，还是原位置本身缺乏可观测因果影响。

**现在：**在原图例前位置，整向量也没有可靠正向效应；在答案前位置，则有
可复算、两种映射一致的方向级 margin 因果效应。因此不要继续在原 marker
位置无限提高 AUROC 或加大扰动，应优先研究位置/处理阶段相关的因果差异。

这仍不是“授权概念已被唯一识别”。答案前位置已经读过字母图例，可能编码
规范性执行/阻止、语义决策或混合信息。正交掉训练字母均值差不能排除全部
非线性或混合的输出计划。两个位置的方向也分别拟合，不能把差异全归于位置，
或称作同一条方向沿时间转化成决策电路。冗余、写入/读取路径尚未定位。

**最小后续建议（未执行）：**冻结当前两个方向，先在新场景上确认这个
位置×干预模式差异，再将两个方向交叉应用到两个位置，检验位置和方向身份
各自的贡献。仍固定少量位置/层，并保留 null、随机和正反映射对照。如果
新场景不能复现，应收缩结论而非继续筛选。只有得到稳定的方向级效应后，
才扩展到授权与实际行动解耦、真实 injection 或自然未授权执行。

## 7. 审计、交付和边界

独立脚本不调用 Stage 4 的汇总函数，检查 donor 配对、源文件和参考文件 hash、
训练方向、位移分解范数、送达信息、原始概率、场景统计、配对差、生成和 null
检查。两种精度均通过。它仍由同一 AI 代理编写，不是独立研究者重跑模型。
原有加新增共 33 项测试通过；后续最终交付还保留源码与数据完整性清单。

原始 Stage 3 档案没有改变。模型权重未训练、未下载；没有提交或推送 GitHub。
此前的测试场景已用于本轮探索，不能在未来又称它们从未被观察过。

- 预注册：`docs/stage4-preregistration.md`。
- 复现说明：`docs/stage4-reproduction.md`。
- 原始输出：`results/stage4/nf4/`、`results/stage4/bf16/`。
- 独立审计：`scripts/audit_stage4.py`，输出汇总 `results/stage4/audit.json`。
- 精确配对子集：`results/stage4/matched_precision_comparison.json`。

本轮最稳妥的结论是：**相同受控任务和固定层下，两个预定位置表现出不同的
干预响应；答案前训练方向支持小幅、跨字母映射的因果 margin 变化，但还没有
改变实际首选答案，也没有回答模型是否知道自己正在违背用户意图。**
