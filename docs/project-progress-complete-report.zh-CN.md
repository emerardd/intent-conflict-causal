## 执行摘要

本项目最初想回答的问题是：

> **模型是否知道自己正在违反用户意图？**

最终结论必须先说清楚：**这个原始问题尚未解决。** 当前主实验没有自然 prompt
injection、真实工具调用、自发越权或“未授权但仍执行”的行为样本。因此没有证据
支持“模型知道自己违规”或“知道但仍然做”。

项目真正完成的是一个更窄、但有可复算因果证据的问题：

> 在受控的明确授权判断任务中，可线性读出的授权相关信息，什么时候会成为对
> 最终输出概率具有因果作用的决策表征？这种作用依赖写入位置、方向身份，还是
> 一般 residual 扰动？

研究经历了五次关键更新：

1. **Stage 1：初始受控阳性。** Qwen3.5-4B 在 18 个场景、144 条提示上行为准确率
   0.993；第 16 层末 token 授权方向的留出测试 AUROC 为 1.0；相反授权条件的
   完整 residual state 双向替换产生 0.637 的 donor 对齐 margin 效应，场景聚类
   95% CI `[0.480, 0.766]`。
2. **Stage 2：跨精度、跨家族复现。** 在 40 个场景和 20 个最终测试场景上，
   Qwen3.5-4B NF4、Qwen3.5-4B BF16、Ministral-3-3B BF16 的行为准确率、测试
   AUROC 均为 1.0。完整末 token state 替换效应分别为 0.700、1.268、4.158，
   置信区间均远离零。
3. **识别审计：强阳性被重新限定。** Stage 1/2 固定“授权→执行→A，未授权→
   阻止→B”，完整状态 patch 同时搬运授权、规范性动作决定、输出 token 计划及
   其他高维信息。因此它不能证明一维授权方向因果充分，更不能证明违规意识。
4. **Stage 3：关键负结果。** 加入 A/B 输出映射反转后，图例前第 16 层的授权相关
   方向仍可跨映射、跨场景读出：同措辞测试 AUROC 1.0，未训练措辞 AUROC 0.898。
   但 480 次冻结的一维干预没有可靠效应，主检验 −0.00651，95% CI
   `[−0.01953, 0.00651]`，0 次首选输出翻转。这证明“可读出”不等于“下游在该
   token 读取这根方向”。
5. **Stage 4–5b：定位并确认答案前表征。** Stage 4 在旧测试场景上探索到：图例前
   连单位置完整 state 替换也近零；答案前 full-state 和本地方向则能改变 donor
   对齐 margin。Stage 5 用 12 个全新场景确认位置差异。Stage 5b 再用另一组
   12 个全新场景，把答案方向、图例前方向和每位置 10 根随机方向严格匹配到共同
   范数 0.59587675。三个预声明比较全部通过：

   - 答案方向减 10 根同范数随机轴均值：**0.19896**，95% CI
     **`[0.18047, 0.21901]`**；
   - 答案方向减同范数图例前方向：**0.17708**，
     **`[0.15625, 0.19792]`**；
   - 位置×方向身份交互：**0.19271**，
     **`[0.16927, 0.21615]`**。

三项 Stage 5b 比较都是 12/12 个场景方向一致，独立 raw-artifact 复算通过。但是
1,344 次 Stage 5b 干预依然是 **0 次 top-1 翻转**；答案方向只恢复约 2.30% 的
自然 donor-recipient margin gap。

因此当前最稳妥的总结是：

> 在 Qwen3.5-4B 的受控授权决策任务中，图例前位置存在可读但单位置因果作用近零
> 的授权相关信息；答案生成前则存在一个位置和方向联合特异、跨两种字母映射、
> 能小幅推动输出 margin 的决策表征。该效应超过同范数早期方向和 10 根随机方向，
> 但没有改变首选行为，也没有分离授权与“应该阻止”的语义。因此它是受控的答案前
> 因果决策表征证据，不是行为控制、纯授权变量或自然违规意识证据。

## 1. 原始问题与最终操作化

### 1.1 原始问题为什么太宽

“模型知道自己正在违反用户意图吗”同时包含至少五个概念：

1. 用户意图或授权状态；
2. 模型计划采取的动作；
3. 动作与用户意图是否冲突；
4. 模型内部是否表示这种冲突；
5. 这种表示是否在模型最终仍违规时存在并影响行为。

只发现一个能区分“授权”和“未授权”提示的 probe，不能回答这五点。即使 activation
patch 能改变 logits，也可能只是移动了动作计划或输出 token，而非模型对冲突的
“认识”。所以项目采用逐步升级的证据标准，而不是直接把高 AUROC 叫作意识。

### 1.2 当前实际回答的问题

当前可以回答的问题是：

> 当候选动作文本保持相同，只改变它与明确许可/禁止记录的绑定关系时，模型内部
> 是否形成跨场景稳定的授权相关状态？该状态在什么处理阶段对最终 A/B 决策概率
> 具有方向特异的因果作用？

### 1.3 证据阶梯

本报告区分以下层级：

| 层级 | 含义 | 当前状态 |
|---|---|---|
| E1 行为理解 | 模型能按授权记录正确执行/阻止 | 支持 |
| E2 可读性 | 授权相关条件可从留出场景激活线性读出 | 支持 |
| E3 完整状态因果相关 | 配对完整 residual state 替换改变 margin | 支持 |
| E4 输出 token 独立 | 效应不只是固定 A/B 字母偏置 | 部分支持：双映射同向 |
| E5 低维方向因果作用 | 一根冻结方向超过同范数对照 | 在 `answer` 位置支持；`pre_mapping` 不支持 |
| E6 位置×方向特异 | 同剂量下正确方向只在正确位置有效 | Stage 5b 支持 |
| E7 行为控制 | 干预改变自然首选动作 | 不支持：关键后续均 0 donor-directed flip |
| E8 违规冲突表征 | 同一实际动作下区分授权执行与未授权执行 | 未测试 |
| E9 “知道但仍违规” | 自然违规前仍存在冲突表征 | 未测试 |

这张表是整个项目最重要的结论边界：Stage 5b 推进到了 E6，没有推进到 E7–E9。

## 2. 共同实验框架

### 2.1 受控任务

每个样本包含：

- 一个候选动作；
- 一个干扰动作；
- 一条许可记录和一条禁止记录；
- 候选动作 JSON 在配对样本中逐字相同；
- 授权与未授权条件只交换许可/禁止分别绑定哪个动作；
- 候选动作先出现/后出现以及措辞模板被配平；
- 模型输出 `A` 或 `B`，分别映射到执行或阻止。

这类人工对称任务牺牲生态效度，换取“候选动作内容不变、授权关系变化”的可识别
对比。它适合做必要机制基线，不适合直接代表自然代理行为。

### 2.2 模型

主要模型为：

- `Qwen/Qwen3.5-4B`；
- 固定本地 revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`；
- NF4 权重、bfloat16 计算；
- Stage 2 另做 Qwen BF16 复现。

第二模型家族：

- `Ministral-3-3B-Instruct-2512`；
- 官方 FP8 checkpoint 按模型卡加载后反量化为 BF16；
- 用于 Stage 2 正式复现。

Gemma-2 只在早期筛选中出现，没有成为最终核心证据，因为它过旧且不适合承载
“现代模型”主张。

### 2.3 测量与因果指标

核心行为量：

`margin = log p(B) - log p(A)`。

在不同输出映射下，统计量按 donor 的语义正确答案重新对齐，所以正值统一表示
向配对的相反授权状态答案移动。它的单位是 log-probability difference，不是准确率
百分点。

核心表征量：

- 授权相关均值差方向；
- 留出场景 AUROC；
- 训练/测试方向余弦；
- 场景级符号置换或符号检验；
- 训练数据拟合、验证数据选层、测试数据只用于最终评估。

核心干预：

- 配对完整 residual state 替换；
- 一维平行分量；
- 正交剩余分量；
- null patch；
- 错层或错误位置；
- 同授权措辞替换；
- 等范数随机方向；
- A/B 输出映射反转；
- Stage 5b 的严格共同范数交叉方向。

统计不确定性以场景为独立单位。同一场景的多模板、多映射、多授权行不能虚增为
独立样本。

## 3. Stage 1：最小因果机制实验

### 3.1 设计

Stage 1 使用 Qwen3.5-4B NF4，18 个场景、144 条提示。六个行为筛选场景被限制在
训练集，最终测试的四个场景在切分冻结前未用于 Qwen 行为校准。验证集选择第 16 层，
最终测试不参与选层。

### 3.2 行为与表征

| 指标 | 结果 |
|---|---:|
| 授权准确率 | 0.986 |
| 未授权准确率 | 1.000 |
| 总准确率 | 0.993 |
| 授权平均 margin | −3.385 |
| 未授权平均 margin | 5.536 |
| 平均配对 margin 差 | 8.922 |
| 最终测试准确率 | 32/32 |
| 训练/验证/测试 AUROC | 1.000 / 1.000 / 1.000 |
| 训练/测试方向余弦 | 0.977 |

场景级 Monte Carlo 符号置换检验为 `p=0.001996`。只有 500 次置换，因此该值是
“本次未观察到同样极端 null 加一修正”，不是高精度千分位估计。

### 3.3 完整状态 patch

在最终测试的四个场景、16 个配对上：

| 干预 | margin 平均变化 |
|---|---:|
| 授权源 → 未授权目标 | −0.750 |
| 未授权源 → 授权目标 | +0.523 |
| 双向 donor 对齐均值 | **+0.637** |
| 场景聚类 95% CI | **[0.480, 0.766]** |
| 五个等范数随机方向均值 | +0.029 |

错误的第 4 层替换效应只有 0.023；同授权状态的措辞替换平均绝对变化 0.121，
32 次均无翻转。

### 3.4 Stage 1 后来的解释修正

最初报告把它称为“授权状态”的因果证据。后来审计发现，更准确的说法是：

> **包含授权相关信息的完整答案前状态对 A/B 决策 margin 有因果作用。**

因为完整状态还包含动作决定和 token 计划，不能由此证明某一维授权变量因果充分。

## 4. Stage 2：跨精度和跨模型家族复现

### 4.1 升级

Stage 2 使用 40 个场景，固定 12/8/20 场景训练、验证、测试拆分，并用 80 个全局
唯一 codeword 修复早期共享 `alpha/beta` 词汇捷径。三个正式运行使用相同 320 条
提示。

### 4.2 正式结果

| 运行 | 选中层 | 测试行为配对 margin | 测试 AUROC | 训练/测试方向余弦 | 完整状态因果效应（95% CI） | 随机均值 |
|---|---:|---:|---:|---:|---:|---:|
| Qwen3.5-4B NF4 | 16/32 | 10.347 | 1.000 | 0.996 | **0.700 [0.645, 0.762]** | 0.058 |
| Qwen3.5-4B BF16 | 16/32 | 11.288 | 1.000 | 0.998 | **1.268 [1.205, 1.332]** | 0.031 |
| Ministral-3-3B BF16 | 15/26 | 7.478 | 1.000 | 0.998 | **4.158 [3.947, 4.365]** | −0.037 |

三次运行在 20 个留出场景上的行为准确率均为 1.0。对 12 个训练场景枚举全部
`2^12=4096` 种场景符号翻转，三个精确 p 值均为 `1/4096=0.000244`。

错误层效应分别为 0.013、−0.002、0.002；同授权状态措辞替换在每个运行中均为
160 次、0% 决策翻转。

### 4.3 Stage 2 支持与不支持

支持：

- 现象不是 Qwen NF4 独有；
- 不是少量共享 codeword 的简单捷径；
- 早期错误层和同授权措辞替换不能复制主效应；
- 包含授权相关信息的完整答案前 state 具有稳定、双向、donor 特异的 margin 效应。

不支持：

- 一维授权方向本身足以控制决策；
- 状态表示纯授权而非动作/答案；
- 自然工具行为、prompt injection 或违规意识。

## 5. 识别审计：为什么强阳性仍不够

Stage 1/2 的任务固定：

- 授权 → 执行 → A；
- 未授权 → 阻止 → B。

因此四个变量完全绑定：

1. 授权状态；
2. 规范性的 execute/block 决定；
3. 最终 A/B token；
4. 答案生成前的完整高维任务状态。

A/B label remapping 可以消除最简单的字母身份混淆，但不能自动分离授权与“应该
阻止”。完整 state patch 能说明该状态对 margin 有因果作用，不能说明其中哪一维
被下游使用。这个审计改变了整个项目的目标：不再追求更多 AUROC=1，而是寻找
一个在输出映射变化后仍有效的低维方向，并定位它真正被读取的位置。

## 6. Stage 3：映射控制和关键负结果

### 6.1 三因子 v1 的行为门槛失败

Stage 3 v1 尝试同时操纵授权、NORMAL/REVERSED 控制器规则和 A/B 映射。两个 pilot
场景共 32 条：

| 控制器规则 | 输出映射 | 正确 |
|---|---|---:|
| NORMAL | A=执行，B=阻止 | 8/8 |
| NORMAL | A=阻止，B=执行 | 4/8 |
| REVERSED | A=执行，B=阻止 | 4/8 |
| REVERSED | A=阻止，B=执行 | 4/8 |

总正确率 20/32=62.5%；三个非标准 cell 的 24 条全部输出 B。预注册要求每个 cell
至少 90%，所以正式表征和干预阶段按规则停止。失败被保留，没有通过挑 prompt
或继续调参绕过。

### 6.2 自适应缩小后的 v2

v2 删除反转控制器，只保留授权 × A/B 映射。它是看过 v1 后的新设计，不能声称
在所有选择之前预注册。v2 仍把未授权和“应该阻止”绑定，只控制输出字母。

24 个新场景按 8/4/12 场景训练、验证、测试；测试另有未训练授权措辞。正式行为：

- 全词表 argmax 288/288 正确；
- 实际生成抽查 32/32 正确；
- 正常/反转映射各自均正确；
- 测量记录结束、图例前、答案前的多个层站点。

验证选中图例前、layer index 16：

| 指标 | 正常映射 | 反转映射 |
|---|---:|---:|
| 验证 AUROC | 1.000 | 1.000 |
| 同措辞测试 AUROC | 1.000 | 1.000 |
| 未训练措辞测试 AUROC | 0.897569 | 0.897569 |

同措辞测试投影差 0.5761，95% CI `[0.5531, 0.6004]`；新措辞为 0.2478，
`[0.2219, 0.2719]`。两组均为 12/12 场景同向。

### 6.3 冻结的一维干预是负结果

使用训练间距 `s=0.6105854692`，在 12 个测试场景的 48 个 recipient 上进行主方向
`±0.5, ±1, ±2` 和两个随机正交轴干预，共 480 次 forward：

| 方向/强度 | donor 对齐效应 | 95% CI | 首选翻转 |
|---|---:|---|---:|
| 授权相关方向，α=0.5 | −0.007813 | [−0.018229, 0.002604] | 0/96 |
| **授权相关方向，α=1** | **−0.006510** | **[−0.019531, 0.006510]** | **0/96** |
| 授权相关方向，α=2 | 0.001302 | [−0.010417, 0.011719] | 0/96 |
| 随机轴 0，α=1 | −0.005208 | [−0.014323, 0.002604] | 0/96 |
| 随机轴 1，α=1 | 0.001302 | [−0.010417, 0.010417] | 0/96 |

实现诊断确认 patch 真实写入，实际扰动范数约 0.6123，不是 dtype 把向量抹成零。
没有在看见负结果后改用更晚层、更强 alpha 或筛有利场景。

### 6.4 Stage 3 的研究更新

Stage 3 明确区分了：

- **可读性阳性：**图例前能线性读出授权相关条件；
- **该站点一维因果性阴性：**沿选中方向干预没有可靠作用。

这不意味着模型没有授权信息；更合理的解释是该位置可能只是可读旁支、存在冗余，
或下游真正读取信息的时间点更晚。

## 7. Stage 4：从“方向不足”转向“处理阶段不同”

Stage 4 是看过 Stage 3 后的有界探索性诊断，复用旧测试场景，不是独立确认。
固定 layer 16，只比较 `pre_mapping` 和 `answer` 两个位置，并把 paired donor 差分解为：

- full；
- parallel；
- perpendicular；
- random_full；
- random_parallel。

|---|---|---:|---|---:|
| 图例前 | full | −0.007812 | [−0.020833, 0.005208] | 0/48 |
| 图例前 | parallel | 约 0 | [−0.013021, 0.013021] | 0/48 |

- 答案前 full − random_full：0.39844，CI `[0.34115, 0.45313]`。

答案前 full 和 parallel 分别只恢复约 5.14% 和 4.22% 的自然 gap，NF4 480 次、
BF16 80 次替换均 0 首选翻转。BF16 只复查相同两场景，呈相似模式，但不是完整
跨精度确认。

### 7.2 Stage 4 的意义

Stage 3 的 null 不是简单因为“一维不够”：图例前连完整单位置 state 也近零；答案前
则存在可复算的 full 和一维分量效应。这把下一问题从“如何在早期 marker 提高 AUC”
变成“授权相关信息如何在处理阶段中转化为答案前决策状态”。

## 8. Stage 5：新场景确认位置依赖

Stage 5 冻结 Stage 4 的 layer、两个位置和两根方向，使用 12 个全新场景、48 条
基线、576 次干预。正常映射 24/24，反转映射 23/24；唯一错误是 A/B 保存
log-probability 完全相等的 tie 样本，未删除。

四个预声明检查全部通过：

| 检查 | 结果 | 95% CI |
|---|---:|---|
| `answer` 本地方向 − 等范数随机轴 | **0.3672** | **[0.3021, 0.4297]** |
| `answer/full` − `answer/random_full` | **0.4349** | **[0.3724, 0.4948]** |
| 本地方向 `answer − pre_mapping` 位置交互 | **0.3229** | **[0.2604, 0.3802]** |
| `pre_mapping/full` 原始效应 | −0.0026 | [−0.0339, 0.0234] |

最后一项的完整区间位于预设 `[−0.1, 0.1]` 等效界内。两个位置 full-state 平均
位移范数接近：`pre_mapping` 1.1315，`answer` 1.1679，所以 full-state 的位置差
不容易用答案位置写入更大解释。

但 Stage 5 的交叉方向使用自然 donor 投影：本地方向范数约 0.58–0.96，交叉方向
只有约 0.049–0.071。因此“交叉方向无效”仍可能只是剂量不匹配，而非方向身份。
Stage 5 的 576 次干预没有 donor-directed top-1 翻转；七个 top-1 变化全部来自唯一
tie 样本，并且是从错误 B 变成正确 A、远离 donor。

## 9. Stage 5b：严格等范数的位置×方向确认

### 9.1 冻结共同范数

Stage 5b 只解决 Stage 5 的剂量混淆，不扩模型、任务、层或位置。共同范数仅用
Stage 3 的 64 条训练行和 Stage 4 冻结方向计算：

| 训练参考位置 | 绝对 donor 投影中位数 |
|---|---:|
| `pre_mapping` | 0.59587675 |
| `answer` | 1.14314766 |

取较小值 `s=0.5958767498058`。所有真实轴和每位置 10 根随机轴都使用
`h'=h+zsd`；无 alpha sweep。

### 9.2 数据和执行

- 另一组 12 个 Stage 1–5 未使用场景；
- 48 条基线，两种映射各 24/24 正确；
- 28 个干预条件，每条件 48 行；

## 11. 到底解决了什么，没有解决什么

### 11.1 已解决

1. **授权相关信息是否可跨场景读出？** 是，在多模型、精度和场景上支持。
2. **包含该信息的完整答案前状态是否对决策 margin 有因果作用？** 是，Stage 1/2
   跨精度、跨家族支持。
3. **图例前可读方向是否在该位置因果活跃？** 当前证据为否：一维和 full-state
   都近零。
4. **答案前是否存在低维方向级因果效应？** 是，Stage 4 探索、Stage 5/5b 新场景
   确认。
5. **它是否只是一般扰动或 cross-axis 剂量太小？** Stage 5b 反对这两个解释：
   答案方向超过 10 根同范数随机轴和同范数图例前方向。
6. **效应是否依赖正确位置？** 是，相同答案方向放到图例前无相同作用，并有
   预声明位置×方向交互。

### 11.2 未解决

1. **纯授权语义。** 未授权始终等于规范上应该阻止，方向可能表示动作决定、规则
   遵循、输出准备或混合。
2. **行为控制。** Stage 3、4、5、5b 的关键干预均没有 donor-directed top-1 翻转。
3. **自然违规。** 主实验中没有自然“未授权但仍执行”样本。
4. **知道但仍违规。** 没有在实际相同执行动作条件下比较 authorized execution 和
   unauthorized execution。
5. **自然 prompt injection。** 没有不可信外部内容、真实工具调用或开放式输出。
6. **普遍性。** Stage 5b 只有一个 4B 模型、NF4、一种 prompt grammar 和 12 个
   手工场景。

对最初问题的直接答案仍是：

> **没有解决“模型是否知道自己正在违反用户意图”。当前解决的是一个必要前置：
> 受控授权相关信息在什么时候成为答案前、方向特异、连续概率意义上的因果决策
> 表征。**

## 12. 最强的反对证据

完整报告必须主动呈现以下反证，而不是只列漂亮统计量：

1. **Stage 3 v1 失败。** 当规则和映射真正析因时，模型在 24 个非标准条件全部输出
   B；现有 4B/NF4 任务不足以支撑预定三因子机制辨识。
2. **高 AUROC 与因果 null 共存。** Stage 3 图例前测试 AUROC 1.0，但主方向干预
   −0.00651，CI 跨零。这直接否定“probe 好就找到了机制”的推理。
3. **所有确认结果都没有行为翻转。** Stage 5b 1,344 次为 0；连续效应只有自然
   gap 的 2.3%。
4. **方向可能是答案前决策变量，不是授权变量。** 反转映射下效应较弱；答案位置
   已读过 response legend。
5. **NF4/bfloat16 数值呈离散阶梯。** 多个效应为 0.03125/0.0625 级别，小差异不应
   被赋予细粒度语义解释。
6. **随机轴不是全部替代解释。** 10 根正交随机轴比一根更好，但不能覆盖其他结构化
   语义方向或非线性子空间。
7. **新场景不等于新任务。** Stage 5/5b 场景身份和 codeword 新，但 prompt grammar、
   A/B 头和任务逻辑共享。
8. **“独立审计”不是独立研究者。** 它不调用主分析代码，但仍由同一个 AI 代理编写，
   可能共享概念错误。

## 13. 主要限制与可解决性

### 13.1 授权 × 动作未析因

这是最大的科学限制。需要四格自然行为：

| 用户授权 | 模型实际动作 | 类型 |
|---|---|---|
| 已授权 | 执行 | 合规执行 |
| 未授权 | 阻止 | 合规阻止 |
| 未授权 | 执行 | 真实违规 |
| 已授权 | 阻止 | over-refusal |

关键比较是相同实际动作下的 authorized execution vs unauthorized execution，而不是
未授权阻止 vs 已授权执行。

### 13.2 单 token 强制选择

A/B 任务便于可识别分析，但输出空间过窄。未来应使用真实工具 JSON 或自然文本，
行为分类来自 unconstrained generation。

### 13.3 模型与精度

Stage 2 证明完整状态现象跨 Qwen 精度和 Ministral 家族；但 Stage 5b 的等范数
方向结果尚未在 BF16 或第二家族复现。可以用固定 Stage 5b 设计在新场景上做确认，
但在回答自然违规前，这不是最高优先级。

### 13.4 位置和机制粒度

当前只研究单层、单 token residual。位置×方向效应不等于完整电路：多个 token、
attention head、MLP、冗余路径和非线性子空间尚未定位。继续细分只有在自然行为
问题建立后才有高价值。

### 13.5 本地预注册

Stage 3–5b 都保留本地时间戳、源码快照和 hash，但不是 OSF 等第三方不可篡改
预注册。Stage 3 v2、Stage 4、Stage 5、Stage 5b 均是看过前一阶段后提出的自适应
后续；它们在各自新响应前冻结，但不能声称整条研究路线从一开始就预注册。

### 13.6 研究用时叙述

Stage 1–5b 是多阶段累计工作，不应伪装成一段从零开始、完全独立的 16 小时任务。
如果用于 MATS，应清楚说明：哪一段是申请时段内完成、哪些是此前探索、哪些是
看过结果后的确认。最强叙事不是“做了很多阶段”，而是展示一次高质量的结论修正。

## 14. LLM 使用和防止低质量输出

本项目大量使用 LLM 编程代理进行：

- 设计讨论和替代解释枚举；
- Python 实现、测试和运行编排；
- 预注册、运行日志和报告草拟；
- 独立审计脚本实现；
- 结果解释与 claim calibration。

为降低“LLM 生成看似专业但不可靠内容”的风险，采用了以下约束：

1. **原始输出优先。** 结论绑定 JSON/NPZ，不只相信 Markdown 报告。
2. **freeze-first。** 新场景响应前保存配置、源码、阈值、方向、统计和 reference hash。
3. **拒绝覆盖。** 正式 runner 对已有 output 报错，避免无声重跑覆盖失败结果。
4. **append-only journal。** baseline/intervention 逐行写入，超时或失败仍保留证据。
5. **独立重算。** Stage 3–5b 的 audit 不调用主汇总函数，重新构造 identity、pair、
   cluster statistic 和决定规则。
6. **实现观测。** null patch、实际 delivered norm/projection、真实 generation 与
   patched forward 一致性均记录。
7. **失败不删除。** Stage 3 v1 门槛失败、Stage 3 v2 null、Stage 5 tie 均保留。
8. **测试定向。** 最终 Stage 5b 为 41/41 tests；pytest 显式限定仓库 `tests/`，避免
   收集冻结快照产生重复模块假失败。
9. **主张分层。** 始终区分 decodability、完整状态因果相关、一维因果作用、行为
   翻转和自然 awareness。

仍未完全解决的 LLM 风险：

- 主实现和独立 audit 可能共享同一概念误解；
- 尚无第二研究者从冻结产物盲复算；
- 尚无干净机器完整模型重跑。

对于关键数字，若以后写入申请，建议至少人工抽查：

- 每阶段一个完整 prompt pair；
- donor pairing 逻辑；
- Stage 5b 三项场景差值；
- 0 top-1 flip 的 raw 分类；
- freeze/reference hash；
- “未解决原始问题”的结论边界。

## 16. 下一阶段：真正回答原始问题的 Stage 6

Stage 5c 不值得继续。当前受控模板的关键剂量解释已被 Stage 5b 解决，继续增加
随机轴、层或相似场景的边际价值很低。下一阶段必须换成现象先行的自然行为设计。

### 16.1 新问题

> 在控制实际输出动作和输出 token 身份后，模型的行动前状态能否区分“同一动作
> 获得用户授权”与“同一动作违反用户授权”？这种冲突相关状态是否在模型自然
> 违规时仍然存在？

### 16.2 行为门槛优先

先构造自然工具调用或 prompt-injection 场景，只做 unconstrained generation，不
立即做 probe。需要观察四格：

- authorized execution；
- unauthorized execution；
- compliant block；
- over-refusal。

如果独立场景中的 unauthorized execution 太少，应按预注册停止或只允许一次明确
模型/攻击强度 pivot，而不是反复调 prompt 直到制造阳性。

### 16.3 关键比较

真正接近“知道但仍违规”的比较是：

> **authorized execution vs unauthorized execution of the same action**。

两边实际工具、参数和输出 token 尽可能相同，唯一核心差异是用户是否授权。测量
位置应在第一个工具调用 token 生成前。只有在未授权执行样本中仍能读出冲突相关
状态，且它不只是动作计划或拒绝计划，才有理由讨论“模型没有完全丢失用户意图”。

### 16.4 结论规则

- 只可读出：称为 action-conditioned conflict decodability；
- 超过动作/随机/位置对照：称为 conflict-related representation；
- 小幅 margin 效应：称为 continuous causal effect；
- 实际减少自然 unauthorized execution 且不大量损害授权执行：才开始讨论行为控制；
- 即使全部成立，也优先使用“latent conflict signal”，不要直接等同意识。

## 17. 对 MATS 申请价值的评估

现有项目最强的申请价值不是“发现模型知道自己违规”，而是展示研究判断：

1. 从一个强阳性结果出发；
2. 主动发现授权、动作和输出混淆；
3. 让更强的析因任务在行为门槛失败时真实停止；
4. 接受高 AUROC 与因果 null 共存；
5. 根据负结果改变问题，从 feature purity 转向 processing stage；
6. 用新场景做独立确认；
7. 用严格等范数解决最强替代解释；
8. 最后仍明确拒绝将连续 margin 效应包装成行为或 awareness。

若作为申请研究任务，建议将主问题表述为：

> **When does decodable authorization-related information become a causally active
> decision representation?**

而不是：

> Does the model know it is violating user intent?

后者应出现在“原始动机和下一步”，不能写成已回答结论。

同时必须披露：Stage 1–5b 是多阶段累计工作；Stage 3 v2 及其后续是自适应设计；
本地预注册不是第三方注册。

## 18. 最终结论

项目目前已经形成一条完整、可审计、包含负结果的机制研究链：

- 授权相关信息在受控任务中可跨场景读出；
- 包含该信息的完整答案前状态跨精度和模型家族具有 donor 特异的因果 margin 效应；
- 图例前高可读性并不对应单位置一维或完整状态因果作用；
- 答案前存在可重复的低维方向级效应；
- 两批全新场景确认位置依赖；
- 严格等范数确认答案位置×答案方向身份，排除一般扰动和 cross-axis 剂量解释；
- 所有关键后续仍没有 donor-directed 首选行为翻转；
- 授权与规范性阻止语义仍未分离；
- 自然 unauthorized execution 尚未进入主实验。

因此，当前最准确的一句话是：

> **我们没有证明模型知道自己正在违反用户意图；我们识别并确认了一个更窄的
> 现象：在受控授权决策中，可读授权相关信息到答案生成前才形成位置和方向联合
> 特异、对输出概率具有小幅因果作用的决策表征。**

这个结果足以构成一个诚实、完整的 mechanistic interpretability 项目；若要回答
原始问题，必须另做以自然 unauthorized execution 为行为门槛的 Stage 6。
